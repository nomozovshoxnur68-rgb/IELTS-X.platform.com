VERCEL DEPLOYMENT FIX
=====================
This package is prepared as a static Vercel deployment:
- Local CSS/JS/image references were repaired to use root-relative paths.
- Navigation links were normalized against the actual files in the project.
- vercel.json adds working aliases for the clean URLs used by the existing UI.
- 404.html keeps the same visual design instead of showing Vercel's default 404.

Important: server.js is an Express-style local server and is not used by the static Vercel build.
The existing /api authentication/admin endpoints therefore require a separate server/API deployment
(or a Vercel-compatible database/API implementation) if you need persistent registration/login/admin data.
